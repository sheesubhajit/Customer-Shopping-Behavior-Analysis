Customer Shopping Behavior Analysis
An end-to-end data analytics project that explores retail customer purchasing patterns, spending behavior, product performance, and subscription trends using Python (Pandas), PostgreSQL, and Power BI.
Project Overview
This project analyzes customer transaction data to identify patterns that can support business decisions around revenue, customer retention, product performance, discounts, and subscriptions.

The workflow includes data cleaning and feature engineering in Python, storing and querying the cleaned data in PostgreSQL, and presenting findings through a Power BI dashboard.
Tech Stack
- Python — data cleaning, preprocessing, and feature engineering
- Pandas — data manipulation and analysis
- PostgreSQL — relational data storage and SQL analysis
- SQLAlchemy and psycopg2 — database connection and data loading
- Power BI — interactive dashboard and visual reporting
Workflow
1. Data cleaning
   - Handled 37 missing review_rating records using category-specific median imputation.
   - Removed promo_code_used because it duplicated the information in discount_applied.
   - Standardized column names to lowercase snake_case.
2. Feature engineering
   - Created age_group using age quartiles: Young Adult, Adult, Middle-aged, and Senior.
   - Converted purchase-frequency labels into day intervals, such as Weekly = 7, Fortnightly = 14, Every 3 Months = 90, and Annually = 365.
3. Database loading
   - Loaded the cleaned records into a PostgreSQL table named customer.
   - Used SQLAlchemy and psycopg2 to connect Python to PostgreSQL.
4. SQL analysis
   - Wrote analytical queries to examine revenue, ratings, discounts, shipping types, subscriptions, customer segments, product rankings, and age-group performance.
5. Dashboarding
   - Used Power BI to visualize category performance, age-group revenue, and subscription distribution.

Business Insights
- Category performance: Clothing leads the categories in revenue and item volume, followed by Accessories, Footwear, and Outerwear.
- Customer demographics: Revenue is relatively balanced across the four age groups, with Young Adults having a slight lead.
- Subscription opportunity: Non-subscribers account for 73% of the buyer volume and the majority of aggregate revenue, suggesting an opportunity to improve subscription conversion.
- Discount behavior: Identifying high-spending discount users and products with high discount application rates can help refine promotional strategies.
- Shipping behavior: The report finds average purchase amounts for Standard and Express shipping to be broadly similar.
- Customer loyalty: Segmenting customers by previous purchases can support targeted retention and lifecycle marketing.
SQL Analysis
The PostgreSQL queries in this project cover:
1. Revenue generated by male and female customers
2. Discount users spending above the overall average purchase amount
3. Top five products by average review rating
4. Average purchase amount for Standard versus Express shipping
5. Purchase count, average purchase, and total purchase for subscribers versus non-subscribers
6. Products with the highest discount application rates
7. New, returning, and loyal customer segmentation
8. Top three most-purchased products within each category using ROW_NUMBER()
9. Subscription distribution among customers with more than five previous purchases
10. Revenue contribution by age group
Strategic Recommendations
- Improve subscription incentives: Test member-only bundles, targeted benefits, and shipping incentives to encourage subscription.
- Cross-sell category anchors: Use popular Clothing products, such as Blouses and Sweaters, to promote related Accessories and Footwear.
- Refine discounts: Consider minimum-spend promotions to encourage larger baskets instead of relying only on blanket discounts.
- Personalize retention campaigns: Tailor communications to new, returning, and loyal customers.
- Optimize inventory: Use product rankings within each category to help identify high-demand items.

Getting Started
1. Clone the repository
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd customer-shopping-behavior-analysis
2. Install Python dependencies
If a requirements.txt file is available:
python -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
On Windows, activate the environment with:
venv\\Scripts\\activate
3. Configure PostgreSQL
- Create a PostgreSQL database.
- Update the database connection settings in your Python script.
- Ensure the required Python packages, including SQLAlchemy and psycopg2, are installed.
- Run the data preparation and loading workflow to populate the customer table.
Security note: Do not commit database passwords, API keys, or other credentials. Store sensitive connection details in environment variables or a local .env file and exclude that file from Git.
4. Run the analysis
Run the relevant Python notebook or script, then execute the SQL queries against the populated PostgreSQL customer table.
5. Open the Power BI dashboard
Open the .pbix file in Power BI Desktop and configure the PostgreSQL connection for your environment if needed.
